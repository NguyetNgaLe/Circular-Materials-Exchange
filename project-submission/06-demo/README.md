# Demo

Kịch bản demo đề xuất:

1. Business User đăng nhập.
2. Tạo doanh nghiệp; Admin duyệt.
3. Seller đăng nguồn cung nhựa PP.
4. Buyer tìm kiếm và gửi Offer.
5. Seller chấp nhận; hệ thống tạo Transaction.
6. Hai bên cập nhật trạng thái và xem timeline.
7. Hoàn tất và tạo Review.

Không demo thanh toán hoặc logistics như chức năng tích hợp thật.
