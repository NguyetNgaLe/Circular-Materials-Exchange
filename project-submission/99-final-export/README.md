# Final Export

Chỉ đặt bản đã được Lead duyệt vào đây:

- `report-pdf`: báo cáo PDF cuối.
- `source-files`: file báo cáo gốc, slide, diagram source và tài liệu được yêu cầu.

Trước khi nộp, kiểm tra không chứa mật khẩu, file thực thi `.exe`, database dump, `node_modules`, thư mục build thừa hoặc tài liệu VTrue/VPoint không liên quan.
