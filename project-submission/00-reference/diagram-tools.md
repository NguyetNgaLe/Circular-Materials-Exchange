# Công cụ và quy tắc xuất sơ đồ

| Nhóm sơ đồ | Công cụ chính | File nguồn |
|---|---|---|
| Cơ cấu tổ chức, State Machine | Mermaid Live Editor | `.mmd` |
| Activity, Class, Package, Use Case, Sequence, Deployment | PlantUML Online Server/Editor | `.puml` |
| Logical Architecture | Structurizr DSL | `.dsl` |
| ERD | dbdiagram.io | `.dbml` |
| Docker/server bản trình bày | diagrams.net; dùng file PlantUML làm nội dung gốc | `.drawio` và/hoặc `.puml` |

## Chuẩn trình bày

- Font dễ đọc, cỡ chữ tương đương tối thiểu 11 pt khi đưa vào Word.
- Tên actor, use case và trạng thái sử dụng thống nhất giữa tất cả hình.
- Mỗi hình có tiêu đề tiếng Việt và mã `Dxx`.
- Ưu tiên nền trắng, màu xanh lá/xanh dương đồng bộ với giao diện hệ thống.
- Không chụp màn hình editor. Phải dùng chức năng Export.
- Xuất SVG để chèn báo cáo và PNG độ rộng tối thiểu 2000 px để dự phòng.
- Không xóa file nguồn sau khi xuất hình.
